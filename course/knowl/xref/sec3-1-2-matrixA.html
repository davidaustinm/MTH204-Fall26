Worksheet Exercise 1.

Suppose
\begin{equation*} A = \left[\begin{array}{rrr} 1\amp0\amp-2\\ 1\amp-1\amp0 \\ -1\amp2\amp1 \end{array}\right]. \end{equation*}
🔗
If \(B = \left[\bvec_1 \ \bvec_2 \ \bvec_3 \right]\) is the inverse of \(A\text{,}\) we could solve the following three equations separately to find the columns of \(B\text{:}\)
\begin{equation*} A\bvec_1 = \evec_1=\threevec100, \ \ \ A\bvec_2 = \evec_2=\threevec010, \ \ \ A\bvec_3 = \evec_3=\threevec001. \end{equation*}
But, we may as well solve them at the same time.
🔗

(a)

To do this, build the augmented matrix
\begin{equation*} \left[ \begin{array}{c|c} A \amp I \\ \end{array} \right] \end{equation*}
and find the reduced row echelon form. How does this produce \(B = A^{-1}\text{?}\) Note: In Sage, you may create the \(3\times3\) identity matrix by identity_matrix(3). You may augment \(A\) using A.augment(identity_matrix(3))
🔗
Solution.
For each of the individual systems of the three equations above, we would use the same row operations every time. If we augment with the identity matrix, the first column corresponds to solving the system \(A\bvec_1 = \evec_1\text{,}\) the second column to solving the system \(A\bvec_2 = \evec_2\text{,}\) and the third with \(A\bvec_3 = \evec_3\text{.}\) Since all use the same row operations, we can solve them together, where the results augmented matrix will hold the three columns of \(B\text{,}\) namely, \(\left[\bvec_1 \ \bvec_2 \ \bvec_3 \right].\) Consider the Sage code and output below.
🔗
Therefore, \(A^{-1} = \begin{bmatrix} \frac{1}{3} \amp \frac{4}{3} \amp \frac{2}{3} \\ \frac{1}{3} \amp \frac{1}{3} \amp \frac{2}{3} \\ -\frac{1}{3} \amp \frac{2}{3} \amp \frac{1}{3} \\ \end{bmatrix}.\)
🔗
🔗
🔗

(b)

Use \(B= A^{-1}\) to solve the equation \(A\xvec = \threevec723\text{.}\)
🔗
Solution.
Multiply both sides by \(B\) such that \({\xvec = B\threevec{7}{2}{3} = 7\threevec{\frac{1}{3}}{\frac{1}{3}}{-\frac{1}{3}} + 2\threevec{\frac{4}{3}}{\frac{1}{3}}{\frac{2}{3}} + 3\threevec{\frac{2}{3}}{\frac{2}{3}}{\frac{1}{3}} = \threevec{7}{5}{0}}\text{.}\)

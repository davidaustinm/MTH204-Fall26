    Worksheet Section 2.4 - Linear independence
    

    Definition 8.

    A set of vectors is called linearly dependent if one of the vectors is a linear combination of the others. Otherwise, the set of vectors is called linearly independent.
    🔗
    🔗

    1.

    Consider the colors activity we did on the first day. Let’s use the elementary school art definitions, say red, blue and yellow are primary colors (and together can make any color), and purple, green, and orange are secondary colors (that can be made of two primary colors).
    🔗

    (a)

    What would you say it means for a set of colors to span all colors? What would you say it means for a set of colors to be linearly independent?
    🔗
    🔗

    (b)

    Put any number of colors (of red, blue, yellow, purple, green, and orange) in each box below satisfying the appropriate conditions, or put X if it’s impossible. Explain your reasoning.
    🔗
    Linearly Dependent Linearly Independent
    Span is all colors
    Span is not all colors
    🔗

    (c)

    Thinking in \(\mathbb{R}^2\) now - can a set of two vectors be linearly dependent?
    🔗
    🔗
    🔗

    2.

    We would like to develop a means to detect when a set of vectors is linearly depen- dent. This activity will point the way.
    🔗

    (a)

    Suppose that we have five vectors in \(\mathbb{R}^4\) that form the columns of a matrix having reduced row echelon form
    \begin{equation*} [\vvec_1 \,\,\, \vvec_2 \,\,\, \vvec_3 \,\,\, \vvec_4 \,\,\, \vvec_5 ] \sim \begin{bmatrix} 1 \amp 0 \amp -1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 2 \amp 0 \amp 3 \\ 0 \amp 0 \amp 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    Is it possible to write one of the vectors \(\vvec_1, \vvec_2, \vvec_3, \vvec_4, \vvec_5\) as a linear combination of the others? If so, show explicitly how one vector appears as a linear combination of some of the other vectors. Is this set of vectors linearly dependent or independent?
    🔗
    🔗

    (b)

    Suppose we have another set of three vectors in \(\mathbb{R}^4\) that form the columns of a matrix having reduced row echelon form
    \begin{equation*} [\wvec_1 \,\,\, \wvec_2 \,\,\, \wvec_3] \sim \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \\ \end{bmatrix}. \end{equation*}
    Is it possible to write one of the vectors \(\wvec_1, \wvec_2, \wvec_3\) as a linear combination of the others? If so, show explicitly how one vector appears as a linear combination of some of the other vectors. Is this set of vectors linearly dependent or independent?
    🔗
    🔗

    (c)

    By looking at the pivot positions, how can you determine whether the columns of a matrix are linearly dependent or independent?
    🔗
    🔗

    (d)

    If one vector in a set is the zero vector, \(\zerovec\text{,}\) can the set of vectors be linearly independent?
    🔗
    🔗

    (e)

    Suppose a set of vectors in \(\mathbb{R}^{10}\) has twelve vectors. Is it possible for this set to be linearly independent?
    🔗
    🔗
    🔗

    3.

    Consider the matrix
    \begin{equation*} A = \left[ \begin{array}{ccc} 3 \amp 2 \amp 0 \\ -1 \amp 0 \amp -2 \\ 2 \amp 1 \amp 1 \\ \end{array} \right] \end{equation*}
    whose columns are the vectors \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{.}\)
    🔗

    (a)

    Give a parametric description of the solution space to the equation \({A\xvec = \zerovec}\text{.}\) (This equation is called "homogeneous" because of the \(\zerovec\text{.}\))
    🔗
    🔗

    (b)

    Find one set of nonzero weights \(c_1\text{,}\) \(c_2\text{,}\) \(c_3\) such that
    \begin{equation*} c_1\vvec_1 + c_2\vvec_2 + c_3\vvec_3 = \zerovec. \end{equation*}
    🔗
    🔗

    (c)

    Use these weights to show that one of the vectors can be written as a linear combination of the others.
    🔗
    🔗

    (d)

    Explain why the vectors \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\) are linearly dependent.
    🔗
    🔗

    (e)

    Do the vectors \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\) span \(\real^3\text{?}\) (Hint: Use part (a).)
    🔗
    🔗
    🔗

    4.

    (a)

    If \(A\) is any matrix, explain why the homogeneous equation \(A\xvec=\zerovec\) is consistent. For instance, is there a vector you can guarantee is a solution?
    🔗
    🔗

    (b)

    What condition on the pivots of \(A\) guarantees that there is solution to the homogeneous equation \(A\xvec=\zerovec\) besides the solution \(\xvec=\zerovec\text{?}\)
    🔗
    🔗

    (c)

    In Problem #3, we saw that having a nonzero solution to the homogeneous equation \({A\xvec=\zerovec}\) enabled us to conclude that the columns of \(A\) are linearly dependent. What condition on the pivots of \(A\) will guarantee that the columns of \(A\) are linearly dependent?
    🔗
    🔗
    🔗

    5.

    Consider the matrix \(A= \left[ \begin{array}{ccc} 0 \amp -1 \amp 1 \\ 1 \amp 3 \amp -1 \\ \end{array} \right]\) whose columns are \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{.}\)
    🔗

    (a)

    Sketch the vectors below. Do you think the vectors are linearly independent or linearly dependent?
    🔗
    🔗

    (b)

    Explain how we know that there is a nonzero solution to the homogeneous equation \(A\xvec=\zerovec\text{.}\)
    🔗
    🔗

    (c)

    Find a nonzero solution to the homogeneous solution \(A\xvec=\zerovec\text{.}\)
    🔗
    🔗

    (d)

    Use this solution to express one of the vectors as a linear combination of the others.
    🔗
    🔗
    🔗

    6.

    (a)

    What condition on the pivots of a matrix \(A\) will guarantee that its columns are linearly independent?
    🔗
    🔗

    (b)

    Suppose that \(\vvec_1,\vvec_2,\ldots,\vvec_n\) are linearly independent vectors in \(\real^9\text{.}\) What can you say about the number of vectors in this set?
    🔗
    🔗

    (c)

    What is the smallest number of vectors that can span \(\real^{13}\text{?}\)
    🔗
    🔗

    (d)

    What is the largest number of vectors in \(\real^{13}\) that are linearly independent?
    🔗
    🔗

    (e)

    Suppose that a set of vectors in \(\real^{13}\) is linearly independent and spans \(\real^{13}\text{.}\) What can you say about the number of vectors?
    🔗
    🔗
    🔗

    Outcomes

    • What does it mean for a set of vectors to be linearly dependent? Linearly independent?
      🔗
      🔗
    • What can you say about the pivots of a matrix if the columns of that matrix are a linearly dependent set of vectors?
      🔗
      🔗
    • What is the maximum number of vectors in \(\mathbb{R}^m\) that can be linearly dependent?
      🔗
      🔗
    • When there is a non-trivial solution to the homogeneous equation \(A\xvec=\zerovec\text{,}\) what can you say about the columns of the matrix \(A\) (in terms of linear dependence/independence)?

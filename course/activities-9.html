    Worksheet Section 2.1 - Vectors and Linear Combinations Part 2
    

    1.

    There’s an important connection between linear combinations and linear systems. Suppose we want to write the vector \(\twovec{1.3}{-1.7}\) as a linear combination of \(\vvec = \twovec{2}{1}\) and \(\wvec = \twovec{1}{2}\text{.}\) Then we want to solve
    \begin{equation*} c \twovec{2}{1} + d \twovec{1}{2} = \twovec{1.3}{-1.7}. \end{equation*}
    Simplifying the left side we find
    \begin{equation*} \twovec{2c+1d}{1c + 2d}= \twovec{1.3}{-1.7}. \end{equation*}
    In other words, we need \(2c+1d = 1.3\) and \(1c+2d = -1.7\text{.}\) This is just a linear system. Use Sage to solve this linear system.
    🔗
    Solution.
    This Sage computation yields \({c=1.4\overline{33}}\) and \({d=-1.5\overline{66}}\text{.}\)
    🔗
    🔗
    🔗

    2.

    Use the process from the previous problem to write \(\twovec{15.2}{7.1}\) as a linear combination of \(\vvec\) and \(\wvec\text{.}\) Use Sage!
    🔗
    Solution.
    We want to solve
    \begin{equation*} c \twovec{2}{1} + d \twovec{1}{2} = \twovec{15.2}{7.1}. \end{equation*}
    Simplifying the left side we find
    \begin{equation*} \twovec{2c+1d}{1c + 2d}= \twovec{15.2}{7.1}. \end{equation*}
    In other words, we need \(2c+1d = 15.2\) and \(1c+2d = 7.1\text{.}\) This is just a linear system.
    🔗
    We can first set up an augmented matrix and then use Sage to solve this linear system.
    🔗
    \begin{equation*} \left[ \begin{array}{rr|r} 2 \amp 1 \amp 15.2 \\ 1 \amp 2 \amp 7.1 \\ \end{array} \right] \end{equation*}
    🔗
    This Sage computation yields \({c=7.7\overline{66}}\) and \({d=-0.\overline{33}}\text{.}\)
    🔗
    🔗
    🔗

    3.

    Nutritional information about a breakfast cereal is printed on the box. For instance, one serving of Frosted Flakes has 111 calories, 140 milligrams of sodium, and 1.2 grams of protein. We may represent this as a vector
    \begin{equation*} \begin{bmatrix} 111 \\ 140\\ 1.2 \end{bmatrix} \end{equation*}
    🔗
    One serving of Cocoa Puffs has 120 calories, 105 milligrams of sodium, and 1.0 grams of protein.
    🔗

    (a)

    Write the vector describing the nutritional content of Cocoa Puffs.
    🔗
    Solution.
    \begin{equation*} \begin{bmatrix} 120 \\ 105\\ 1 \end{bmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    Suppose you eat \(c\) servings of Frosted Flakes and \(d\) servings of Cocoa Puffs. Use the language of vectors and linear combinations to express the total amount of calories, sodium, and protein you have consumed.
    🔗
    Solution.
    \begin{equation*} c\begin{bmatrix} 111 \\ 140\\ 1.2 \end{bmatrix} + d\begin{bmatrix} 120 \\ 105\\ 1 \end{bmatrix} = \begin{bmatrix} \textrm{total calories} \\ \textrm{total sodium} \\ \textrm{total protein} \end{bmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (c)

    How many servings of each cereal have you eaten if you have consumed 342 calories, 385 milligrams of sodium, and 3.4 grams of protein. Use Sage!
    🔗
    Solution.
    For these total consumed amounts, we have the corresponding augmented matrix:
    \begin{equation*} \left[ \begin{array}{rr|r} 111 \amp 120 \amp 342 \\ 140 \amp 105 \amp 385 \\ 1.2 \amp 1 \amp 3.4 \\ \end{array} \right] \end{equation*}
    🔗
    Using Sage, we see that we need \(c = 2\) servings of Frosted Flakes and \(d = 1\) serving of Cocoa Puffs.
    🔗
    🔗
    🔗

    (d)

    Suppose your sister consumed 250 calories, 200 milligrams of sodium, and 4 grams of protein at breakfast. What can you conclude about her breakfast? Use Sage!
    🔗
    Solution.
    For these total consumed amounts, we have the corresponding augmented matrix:
    \begin{equation*} \left[ \begin{array}{rr|r} 111 \amp 120 \amp 250 \\ 140 \amp 105 \amp 200 \\ 1.2 \amp 1 \amp 4 \\ \end{array} \right] \end{equation*}
    🔗
    Using Sage, we see that there is no solution due to a pivot in the augmented column. Thus, there is no combination of Frosted Flakes and Cocoa Puffs your sister could’ve eaten to get these totals. She must’ve had something besides these cereals for breakfast!
    🔗
    🔗
    🔗
    🔗

    4.

    Consider the vectors \(\vvec=\twovec{-1}1\) and \(\wvec=\twovec{2}{-2} \text{.}\)
    🔗

    (a)

    Sketch the two vectors on the grid below.
    🔗
    Solution.
    🔗
    🔗

    (b)

    What do you notice about the two vectors? Can you relate them algebraically?
    🔗
    Solution.
    The two vectors are scalar multiplies of each other: \(\vvec = -2\wvec\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Can you write \(\uvec=\twovec{3}{0}\) as a linear combination of \(\vvec\) and \(\wvec\text{?}\) Think geometrically for this question.
    🔗
    Solution.
    No, we can only travel along the line formed by the scalar multiples of \(\vvec\text{.}\) Adding any scalar multiple of \(\wvec\) is still a scalar multiple of \(\vvec\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Now thinking algebraically, what do you get when you find the reduced row echelon form of \([ \vvec \,\,\, \wvec \mid \uvec]\text{.}\) Why should you expect an inconsistent system?
    🔗
    Solution.
    Setting up the augmented system we have the following:
    🔗
    \begin{equation*} \left[ \begin{array}{rr|r} -1 \amp 2 \amp 3 \\ 1 \amp -2 \amp 0 \\ \end{array} \right] \end{equation*}
    🔗
    No solutions since there is a pivot in the rightmost column. This is what we expect since we can’t write \(\uvec\) as a linear combination of \(\vvec\) and \(\wvec\text{.}\)
    🔗
    🔗
    🔗

    5.

    Let’s look at the vectors
    \begin{equation*} \vvec_1 = \fourvec{4}021, \vvec_2 = \fourvec1{-3}31,\vvec_3 = \fourvec{-2}110, \bvec = \fourvec012{-2}. \end{equation*}
    🔗

    (a)

    One thing we can do is ask if \(\bvec\) can be expressed as a linear combination of \(\vvec_1, \vvec_2, \vvec_3\) with weights \(c_1, c_2, c_3\text{.}\) Write out the equation for that linear combination.
    🔗
    Solution.
    \begin{equation*} c_1\vvec_1 + c_2\vvec_2 + c_3\vvec_3 = \bvec \end{equation*}
    🔗
    🔗
    🔗

    (b)

    We can rephrase this question by writing a linear system for the weights \(c_1, c_2, c_3\text{.}\) Solve this linear system (use Sage!).
    🔗
    Solution.
    From Part (a) we want to solve for the values of \(c_1, c_2\text{,}\) and \(c_3\text{.}\) This gives a system of linear equations of:
    🔗
    \begin{equation*} \ds \begin{alignedat}{4} 4c_1 \amp {}+{} \amp c_2 \amp {}-{} \amp 2c_3 \amp {}={} \amp 0 \\ \amp \amp -3c_2 \amp {}+{} \amp c_3 \amp {}={} \amp 1 \\ 2c_1 \amp {}+{} \amp 3c_2 \amp {}+{} \amp c_3 \amp {}={} \amp 2 \\ c_1 \amp {}+{} \amp c_2 \amp \amp \amp {}={} \amp -2 \\ \end{alignedat} \end{equation*}
    🔗
    Converting this to an augmented system we have:
    \begin{equation*} \left[ \begin{array}{rrr|r} 4 \amp 1 \amp -2 \amp 0 \\ 0 \amp -3 \amp 1 \amp 1 \\ 2 \amp 3 \amp 1 \amp 2 \\ 1 \amp 1 \amp 0 \amp -2 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \\ \end{array} \right] \end{equation*}
    🔗
    Using Sage we have that there is no solution.
    🔗
    🔗
    🔗

    (c)

    Can \(\bvec\) be written as a linear combination of \(\vvec_1, \vvec_2, \vvec_3\text{?}\)
    🔗
    Solution.
    Since there is no solution to the linear system, \(\bvec\) cannot be expressed as a linear combination of \(\vvec_1, \vvec_2\text{,}\) and \(\vvec_3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    6.

    Consider the following linear system:
    \begin{equation*} \ds \begin{alignedat}{4} 3x_1 \amp {}+{} \amp 2x_2 \amp {}-{} \amp x_3 \amp {}={} \amp 4 \\ x_1 \amp \amp \amp {}+{} \amp 2x_3 \amp {}={} \amp 0 \\ -x_1 \amp {}-{} \amp x_2 \amp {}+{} \amp 3x_3 \amp {}={} \amp 1 \\ \end{alignedat} \end{equation*}
    🔗

    (a)

    Identify the vectors \(\vvec_1, \vvec_2, \vvec_3,\) and \(\bvec\text{.}\)
    🔗
    Solution.
    \begin{equation*} \vvec_1 = \threevec{3}{1}{-1}, \vvec_2 = \threevec1{2}{0}{-1},\vvec_3 = \threevec{-1}{2}{3}, \bvec = \threevec{4}{0}{1}. \end{equation*}
    🔗
    🔗
    🔗

    (b)

    Rephrase the question "Is this linear system consistent?" by asking "Can \(\bvec\) be expressed as a linear combination of \(\vvec_1, \vvec_2,\) and \(\vvec_3\text{?}\)" What’s the answer to this question?
    🔗
    Solution.
    Converting this to an augmented system we have:
    \begin{equation*} \left[ \begin{array}{rrr|r} 3 \amp 2 \amp -1 \amp 4 \\ 1 \amp 0 \amp 2 \amp 0 \\ -1 \amp -1 \amp 3 \amp 1 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp -4 \\ 0 \amp 1 \amp 0 \amp 9 \\ 0 \amp 0 \amp 1 \amp 2 \\ \end{array} \right] \end{equation*}
    🔗
    Using Sage we have that there is a unqiue solution such that \(\bvec\) can be expressed as a linear combination of \(\vvec_1, \vvec_2,\) and \(\vvec_3\text{.}\) Namely, \({\bvec = -4\vvec_1 + 9\vvec_2 + 2\vvec_3}\text{.}\)
    🔗
    🔗
    🔗
    🔗

    7.

    Consider the vectors
    \begin{equation*} \vvec_1 = \threevec{0}{-2}{1}, \vvec_2 = \threevec1{1}{1}{-1},\vvec_3 = \threevec{2}{0}{-1}, \bvec = \threevec{-1}{3}{-1}. \end{equation*}
    🔗

    (a)

    Can \(\bvec\) be expressed as a linear combination of \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{?}\) If so, can \(\bvec\) be written as a linear combination of the vectors in more than one way?
    🔗
    Solution.
    Consider
    \begin{equation*} c_1\vvec_1 + c_2\vvec_2 + c_3\vvec_3 = \bvec \end{equation*}
    🔗
    This yields the augmented system of
    \begin{equation*} \left[ \begin{array}{rrr|r} 0 \amp 1 \amp 2 \amp -1 \\ -2 \amp 1 \amp 0 \amp 3 \\ 1 \amp -1 \amp -1 \amp -1 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 1 \amp -2 \\ 0 \amp 1 \amp 2 \amp -1 \\ 0 \amp 0 \amp 0 \amp 0 \\ \end{array} \right] \end{equation*}
    🔗
    This gives the following solution in parametric form: \({c_1 = -c_3 - 2}\) and \({c_2 = -2c_3 - 1}\text{,}\) where \(c_3\) is free. Yes, \(\bvec\) can be written as a linear combination of \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\) since the augmented system is consistent. Since the linear system has infinitely many solution, there is more than one way to write the linear combination. For example, \(c_1 = -2\text{,}\) \(c_2 = -1\text{,}\) and \(c_3 = 0\) is one possible linear combination. Another is \({c_1 = -3}\text{,}\) \({c_2 = -3}\text{,}\) and \({c_3 = 1}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Considering the same vectors \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{,}\) can we write every three-dimensional vector \(\bvec\) as a linear combination of these vectors? Explain how the pivot positions in the matrix \([ \vvec_1 \,\,\, \vvec_2 \,\,\, \vvec_3]\) help answer this question.
    🔗
    Solution.
    No!
    \begin{equation*} [ \vvec_1 \,\,\, \vvec_2 \,\,\, \vvec_3] = \left[ \begin{array}{rrr} 0 \amp 1 \amp 2 \\ -2 \amp 1 \amp 0 \\ 1 \amp -1 \amp -1 \\ \end{array} \right] \sim \left[ \begin{array}{rrr} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 2 \\ 0 \amp 0 \amp 0 \\ \end{array} \right] \end{equation*}
    🔗
    which has pivots in only the 1st and 2nd row. The 3rd row leaves the possibility of having an equation of \(0c_1 + 0c_2 + 0c_3 = 1\text{,}\) which has no solutions.
    🔗
    🔗
    🔗
    🔗

    8.

    Now consider the vectors
    \begin{equation*} \vvec_1 = \threevec{0}{-2}{1}, \vvec_2 = \threevec1{1}{1}{-1},\vvec_3 = \threevec{1}{-1}{-2}, \bvec = \threevec{0}{8}{4}. \end{equation*}
    🔗

    (a)

    Can \(\bvec\) be expressed as a linear combination of \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{?}\) If so, can \(\bvec\) be written as a linear combination of the vectors in more than one way?
    🔗
    Solution.
    Consider
    \begin{equation*} c_1\vvec_1 + c_2\vvec_2 + c_3\vvec_3 = \bvec \end{equation*}
    🔗
    This yields the augmented system of
    \begin{equation*} \left[ \begin{array}{rrr|r} 0 \amp 1 \amp 1 \amp 0 \\ -2 \amp 1 \amp -1 \amp 8 \\ 1 \amp -1 \amp -2 \amp 4 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 4 \\ 0 \amp 0 \amp 1 \amp -4 \\ \end{array} \right] \end{equation*}
    🔗
    This gives the following solution in parametric form: \({c_1 = 0}\text{,}\) \({c_2 = 4}\text{,}\) and \(c_3 = -4\text{.}\) Yes, \(\bvec\) can be written as a linear combination of \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\) since the augmented system is consistent. Since the linear system has one unique solution (no free variable), there is only one way to write the linear combination of the vectors.
    🔗
    🔗
    🔗

    (b)

    Considering the same vectors \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\text{,}\) can we write every three-dimensional vector \(\bvec\) as a linear combination of these vectors? Explain how the pivot positions in the matrix \([ \vvec_1 \,\,\, \vvec_2 \,\,\, \vvec_3]\) help answer this question.
    🔗
    Solution.
    Yes!
    \begin{equation*} [ \vvec_1 \,\,\, \vvec_2 \,\,\, \vvec_3] = \left[ \begin{array}{rrr} 0 \amp 1 \amp 1 \\ -2 \amp 1 \amp -1 \\ 1 \amp -1 \amp -2 \\ \end{array} \right] \sim \left[ \begin{array}{rrr} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array} \right] \end{equation*}
    🔗
    which doesn’t allow for a pivot position in the last column of the augmented matrix. Therefore, this system will always be consistent and any \(\bvec\) can be written as a linear combination of the 3 given vectors.
    🔗
    🔗

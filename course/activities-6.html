    Worksheet Section 1.2 - Reduced row echelon form (Part 2)
    

    There is a special class of matrices whose form makes it especially easy to describe the solution space of the corresponding linear system. As we describe the properties of this class of matrices, it may be helpful to consider an example, such as the following matrix.
    \begin{equation*} \begin{bmatrix} 1 \amp * \amp 0 \amp * \amp 0 \amp * \\ 0 \amp 0 \amp 1 \amp * \amp 0 \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ \end{bmatrix} \end{equation*}
    🔗

    Definition 3.

    We say that a matrix is in reduced row echelon form if the following properties are satisfied.
    • If the entries in a row are all zero, then the same is true of any row below it.
      🔗
      🔗
    • If we move across a row from left to right, the first nonzero entry we encounter is 1. We call this the leading entry in the row.
      🔗
      🔗
    • The leading entry in any row is to the right of the leading entries in all the rows above it.
      🔗
      🔗
    • A leading entry is the only nonzero entry in its column.
      🔗
      🔗
    We call a matrix in reduced row echelon form a reduced row echelon matrix.
    🔗
    🔗
    We have been intentionally vague about whether the matrix we are considering is an augmented matrix corresponding to a linear system or a coefficient matrix since we will consider both possibilities in the future.
    🔗

    1.

    When practicing Gaussian Elimination, you might have noticed it was easier to read off the solution when the augmented matrix is in a particular form. This is the reduced row echelon form! Give an example of a matrix in reduced row echelon form, and one that isn’t.
    🔗
    🔗

    2.

    Consider each of the following augmented matrices. Determine if these matrices are in reduced row echelon form. If a matrix is not in reduced row echelon form, perform a sequence of scaling, interchange, and replacement operations to obtain a row equivalent matrix that is in reduced row echelon form. Then use the reduced row echelon matrix to determine whether there is a single solution, infinitely many solutions, or no solutions. If there are infinitely many, identify free and basic variables.
    🔗

    (a)

    \(\ds \left[ \begin{array}{rrr|r} 2 \amp 0 \amp 4 \amp -8 \\ 0 \amp 1 \amp 3 \amp 2 \\ \end{array} \right]\)
    🔗
    🔗

    (b)

    \(\ds \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp -1 \\ 0 \amp 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 1 \amp 1 \\ \end{array} \right]\)
    🔗
    🔗

    (c)

    \(\ds \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 4 \amp 2 \\ 0 \amp 1 \amp 3 \amp 2 \\ 0 \amp 0 \amp 0 \amp 1 \\ \end{array} \right]\)
    🔗
    🔗

    (d)

    \(\left[ \begin{array}{rrr|r} 0 \amp 1 \amp 3 \amp 2 \\ 0 \amp 0 \amp 0 \amp 0 \\ 1 \amp 0 \amp 4 \amp 2 \\ \end{array} \right]\)
    🔗
    🔗

    (e)

    \(\ds \left[ \begin{array}{rrr|r} 1 \amp 2 \amp -1 \amp 2 \\ 0 \amp 1 \amp -2 \amp 0 \\ 0 \amp 0 \amp 1 \amp 1 \\ \end{array} \right]\)
    🔗
    🔗
    🔗

    3.

    More on reduced row echelon form:
    🔗

    (a)

    Suppose that the reduced row echelon form of a matrix looks like
    \begin{equation*} \ds \left[ \begin{array}{rrrr|r} 1 \amp * \amp 0 \amp * \amp * \\ 0 \amp 0 \amp 1 \amp * \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \\ \end{array} \right]. \end{equation*}
    What, if anything, does the last row tell you about the solution space?
    🔗
    🔗

    (b)

    Suppose that the reduced row echelon form of a matrix looks like
    \begin{equation*} \ds \left[ \begin{array}{rrrr|r} 1 \amp * \amp 0 \amp * \amp * \\ 0 \amp 0 \amp 1 \amp * \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ \end{array} \right]. \end{equation*}
    What, if anything, does the last row tell you about the solution space?
    🔗
    🔗

    (c)

    If a linear system has no solutions, how can you tell by looking at the reduced row echelon form of its augmented matrix.
    🔗
    🔗
    🔗

    4.

    Consider the system of linear equations:
    🔗
    \(\ds \begin{alignedat}{4} x \amp {}+{} \amp 2y \amp {}-{} \amp z \amp {}={} \amp 2 \\ -2x \amp {}-{} \amp 2y \amp {}+{} \amp 4z \amp {}={} \amp -4 \\ x \amp {}-{} \amp 2y \amp {}-{} \amp 6z \amp {}={} \amp 3 \\ \end{alignedat}\)
    🔗
    Form the associated augmented matrix and perform Gaussian elimination (or use Sage) to find its reduced row echelon form. What does this tell you about the solution space of the system?
    🔗
    🔗

    Outcomes

    Make sure you can answer the following questions:
    🔗
    • When is a matrix in reduced row echelon form?
      🔗
      🔗
    • Describe how to put a matrix in reduced row echelon from.
      🔗
      🔗
    • How do we use the reduced row echelon form to determine the solution space?
      🔗

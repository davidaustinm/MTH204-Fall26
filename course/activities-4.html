    Worksheet Section 1.1- What can we expect
    

    1.

    Motivation: The Grand Rapids Children’s Museum charges $12 admission for adults and $5 admission for children (ages 3-17). One day, they know the revenue was $900 and the total number of people was 110, but your boss isn’t sure how many children and how many adults. Is there only one answer? Can you figure it out?
    🔗
    Solution.
    First, let’s decide on the variables for our equations. Let \(A\) be the number of adults and \(C\) be the number of children. Then we can write two equations based on the information given:
    \begin{equation*} 12A + 5C = 900 \end{equation*}
    \begin{equation*} A + C = 110 \end{equation*}
    We can solve this system of equations using substitution or elimination. Let’s use elimination. We can multiply the second equation by -12 to get:
    \begin{equation*} -12A - 12C = -1320 \end{equation*}
    Adding this to the first equation:
    \begin{equation*} (12A + 5C) + (-12A - 12C) = 900 + (-1320) \end{equation*}
    Simplifying:
    \begin{equation*} -7C = -420 \end{equation*}
    Solving for \(C\text{:}\)
    \begin{equation*} C = 60 \end{equation*}
    Substituting back into the second equation:
    \begin{equation*} A + 60 = 110 \end{equation*}
    Solving for \(A\text{:}\)
    \begin{equation*} A = 50 \end{equation*}
    Therefore, there is a unique solution: 50 adults and 60 children. Note that we can do this process multiple different ways.
    🔗
    🔗
    🔗

    2.

    What is a line? What is a linear equation? Try to think both algebraically and geometrically (on a graph)! (Save this answer - we’ll come back to it.)
    🔗
    Solution.
    There can be many answers to this, but some things to think about are:
    • A line is a set of points that satisfy a linear equation.
      🔗
      🔗
    • A linear equation is an equation that can be written in the form \({Ax + By = C}\) where \(A\text{,}\) \(B\text{,}\) and \(C\) are constants.
      🔗
      🔗
    • Geometrically, a linear equation represents a straight line on a graph.
      🔗
      🔗
    • Algebraically, it represents a relationship between two variables that can be expressed in the form of a linear equation.
      🔗
      🔗
    • The slope of a line is constant -- there is no curvature.
      🔗
      🔗
    • A line extends infinitely in both directions and has no endpoints.
      🔗
      🔗
    🔗
    🔗
    🔗

    3.

    We’ll now consider linear systems in two variables: By a system of linear equations or a linear system, we mean a set of linear equations written in a common set of unknowns.
    🔗

    (a)

    As a warmup we saw a few "linear systems" in two variables, e.g., \(-x + y = 1\) and \(2x - y = 1\) is a linear system in the two variables \(x\) and \(y\text{.}\) We can visualize a linear system in two variables as a collection of lines in the plane. A solution to the linear system is a point that satisfies both equations, which is the same as saying where the two lines intersect. Here are the ways we say that lines can intersect.
    🔗
    Are there any other ways lines could intersect? Based on your answer, what are the possibilities for the solutions of a system of linear equations in two variables? Note we call the intersections the solution set to the linear system.
    🔗
    Solution.
    There are no other ways lines could intersect. Therefore, the possibilities for the solutions of a system of linear equations in two variables are:
    • Exactly one solution (the lines intersect at a single point, see left graph)
      🔗
    • No solutions (the lines are parallel and do not intersect, see middle graph)
      🔗
    • Infinitely many solutions (the lines are the same line, see right graph)
      🔗
    🔗
    🔗
    🔗

    (b)

    Based on the image below and prior knowledge - what happens to the number of solutions as we add more equations?
    🔗
    Solution.
    A single line has infinitely many solutions (left graph), two lines can intersect at a single point giving one solution (middle graph), and three lines may have no common point of intersection and thus, no solutions. As we add more equations, it is less likely to have common intersections and thus, the number of solutions generally decreases.
    🔗
    🔗
    🔗
    🔗

    4.

    We’ll now consider linear systems in three variables. An example of a linear equation in three variables is \(3x+2y+z = 1\text{.}\) A linear equation in three variables (think \(x\text{,}\) \(y\text{,}\) and \(z\) ) is a plane. Here we’ll use \(3\times5\) index cards, or pieces of paper, or whatever you have that looks like a flat surface, to study the solutions to systems of linear equations in three variables. Again, a solution to a system of linear equations is a point (or points) that satisfy all the equations, ie., an intersection.
    🔗

    (a)

    Is it possible that there are no solutions to a system of two equations in three variables? If so, explain how or sketch an example.
    🔗
    Solution.
    Yes, it is possible that there are no solutions to a system of two equations in three variables. This can happen if the two planes represented by the equations are parallel and do not intersect.
    🔗
    🔗
    🔗

    (b)

    Is it possible that the solutions to a system of two equations in three variables is a single point? If so, explain how or sketch an example.
    🔗
    Solution.
    No, it is not possible for the solutions to a system of two equations in three variables to be a single point. Two planes in three-dimensional space can either be parallel (no intersection), intersect along a line (infinitely many points), or be the same plane (also infinitely many points). Therefore, a single point of intersection cannot occur with just two planes. This is due to the system being "underconstrained."
    🔗
    🔗
    🔗

    (c)

    If you are studying a system of two equations in three variables, what would you usually expect for the solution set?
    🔗
    Solution.
    Usually a line, but there could be no intersection.
    🔗
    🔗
    🔗

    (d)

    If you are studying a system of three equations in three variables, what would you usually expect for the solution set?
    🔗
    Solution.
    Usually a point, but we could also get a line or no solutions.
    🔗
    🔗
    🔗

    (e)

    If you are studying a system of four equations in three variables, what would you usually expect for the solution set?
    🔗
    Solution.
    Usually no solutions as this is "overconstrained."
    🔗
    🔗
    🔗

    (f)

    Is it possible that the solutions to four equations in three unknowns form a line? Either sketch an example or state a reason why it can’t happen.
    🔗
    Solution.
    Yes! It is possible for the solutions to four equations in three unknowns to form a line. This can occur if the four planes represented by the equations intersect in such a way that they share a common line of intersection.
    🔗
    🔗
    🔗

    (g)

    Suppose we have a set of 500 linear equations in 10 unknowns. Which of the would you expect to hold?
    🔗
    Solution.
    In a system of 500 linear equations in 10 unknowns, we would generally expect there to be no solutions. This is because there are more equations than unknowns, which typically leads to an overdetermined system. In such cases, it is likely that the equations will contradict each other, resulting in no common solution. The system is overconstrained, meaning that there are too many constraints for the number of variables available to satisfy them all simultaneously.
    🔗
    🔗
    🔗

    (h)

    Suppose we have a set of 10 linear equations in 500 unknowns. Which of the three possibilities would you expect to hold?
    🔗
    Solution.
    In a system of 10 linear equations in 500 unknowns, we would generally expect there to be infinitely many solutions. This is because there are more unknowns than equations, which typically allows for a larger solution space. The system is underdetermined, meaning that there are not enough constraints to uniquely determine the values of all the unknowns. Therefore, we would expect the solution set to be infinite. There are many variables to play around with, but only a few equations to satisfy -- many "degrees of freedom."
    🔗
    🔗
    🔗

    (i)

    What happens to the size of the solution sets as we add more equations?
    🔗
    Solution.
    As we add more equations to a system of linear equations, the size of the solution set generally decreases. This is because each additional equation imposes an additional constraint on the variables, which can reduce the number of possible solutions.
    🔗
    🔗
    🔗
    🔗

    Definition 1.

    A linear equation in the unknowns \(x_1, x_2, \ldots, x_n\) may be written in the form
    \begin{equation*} a_1x_1 + a_2x_2 + \ldots + a_nx_n = b, \end{equation*}
    where \(a_1, a_2, \ldots, a_n\) are real numbers knowns as coefficients. We also say that \(x_1, x_2, \ldots, x_n\) are the variables in the equation.
    🔗
    By a system of linear equations or a linear system, we mean a set of linear equations written in a common set of unknowns.
    🔗
    🔗

    Definition 2.

    A solution to a linear system is simply a set of numbers \({x_1 = s_1, x_2 = s_2, \ldots, x_n = s_n}\) that satisfy all the equations in the system.
    🔗
    🔗

    5.

    Consider the above important definitions from your textbook when thinking about the following problems:
    🔗

    (a)

    Which of the following equations are linear? Justify your response.
    🔗
    (i)
    \(2x + xy - 3y^2 = 2\)
    🔗
    Solution.
    This equation is not linear because it contains the term \(xy\text{,}\) which is a product of two variables, and the term \(y^2\text{,}\) which is a variable raised to a power greater than 1. A linear equation must have each variable to the first power and cannot have products of variables.
    🔗
    🔗
    🔗
    (ii)
    \(-2x_1 + 3x_2 + 4x_3 - x_5 = 0\)
    🔗
    Solution.
    This equation is linear because it has each variable to the first power and no products of variables. It has the same form as the definition with \(b = 0\) and \(a_4 = 0\text{.}\)
    🔗
    🔗
    🔗
    (iii)
    \(x = 3z - 4y\)
    🔗
    Solution.
    This equation is linear because it has each variable to the first power and no products of variables. This can be rewritten as \(x + 4y - 3z = 0\text{.}\)
    🔗
    🔗
    🔗
    (iv)
    \(\sin(x_1) + \cos(x_2) = 3\)
    🔗
    Solution.
    This equation is not linear because it contains the terms \(\sin(x_1)\) and \(\cos(x_2)\text{,}\) which are trigonometric functions of the variables. A linear equation must have each variable to the first power and cannot have functions of the variables.
    🔗
    🔗
    🔗
    🔗

    (b)

    Consider the system of linear equations:
    🔗
    \begin{equation*} \ds \begin{alignedat}{4} x \amp {}+{} \amp y \amp \amp {}={} \amp 3 \\ \amp \amp y \amp {}-{} z \amp {}={} \amp 2 \\ 2x \amp {}+{} \amp y \amp {}+{} z \amp {}={} \amp 4 \\ \end{alignedat} \end{equation*}
    🔗
    (i)
    Is \((x,y,z) = (1,2,0)\) a solution?
    🔗
    Solution.
    To be a solution, the point must satisfy all three equations. Let’s check: Plugging in \((x,y,z) = (1,2,0)\) into the first equation:
    \begin{equation*} 1 + 2 = 3 \end{equation*}
    This is true. Now the second equation:
    \begin{equation*} 2 - 0 = 2 \end{equation*}
    This is also true. Now the third equation:
    \begin{equation*} 2(1) + 2 + 0 = 4 \end{equation*}
    This is also true. Since the point satisfies all three equations, \((1,2,0)\) is indeed a solution to the system of equations.
    🔗
    🔗
    🔗
    (ii)
    Is \((x,y,z) = (-2,1,0)\) a solution?
    🔗
    Solution.
    To be a solution, the point must satisfy all three equations. Let’s check: Plugging in \((x,y,z) = (-2,1,0)\) into the first equation:
    \begin{equation*} -2 + 1 = -1 \neq 3 \end{equation*}
    This is false. Therefore, \((-2,1,0)\) is not a solution to the system of equations. Note, we don’t need to check the other equations, since that won’t change that the point doesn’t satisfy the first equation.
    🔗
    🔗
    🔗
    (iii)
    Is \((x,y,z) = (0,-3,1)\) a solution?
    🔗
    Solution.
    To be a solution, the point must satisfy all three equations. Let’s check: Plugging in \((x,y,z) = (0,-3,1)\) into the first equation:
    \begin{equation*} 0 + (-3) = -3 \neq 3 \end{equation*}
    This is false. Therefore, \((0,-3,1)\) is not a solution to the system of equations.
    🔗
    🔗
    🔗
    (iv)
    Can you find a solution in which \(y = 0\text{?}\)
    🔗
    Solution.
    If \(y = 0\text{,}\) then the system of equations becomes:
    \begin{equation*} x + 0 = 3 \implies x = 3 \end{equation*}
    \begin{equation*} 0 - z = 2 \implies z = -2 \end{equation*}
    \begin{equation*} 2(3) + 0 + (-2) = 4 \implies 6 - 2 = 4 \end{equation*}
    This is true. Therefore, a solution with \(y = 0\) is \((x,y,z) = (3,0,-2)\text{.}\)
    🔗
    🔗
    🔗
    (v)
    Do you think there are other solutions?
    🔗
    Solution.
    Yes! We have two solutions already: \((1,2,0)\) and \((3,0,-2)\text{.}\) This suggests that there are infinitely many solutions to this system of equations.
    🔗
    🔗

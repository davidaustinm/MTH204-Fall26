    Section Learning Targets

    1. I can execute the next 2-3 steps of Gaussian elimination by hand that are needed to work toward RREF (and recognize that additional steps are needed to achieve RREF), and identify which row operations were used. (Section 1.2).
      🔗
    2. I can use information about pivots to make conclusions about the solutions of a system of linear equations, and explain the underlying reasoning (using appropriate terminology) regarding the existence and uniqueness of solutions and consistency or inconsistency of a system. (Section 1.4)
      🔗
    3. I can determine if and how a given vector can be written as a linear combination of a given set of vectors and explain what this means geometrically. (Section 2.1)
      🔗
    4. I can represent a linear system in three different ways and be able to translate back and forth among the forms: as \(A\xvec = \bvec\text{,}\) as a question about linear combinations, and as a question about an augmented matrix (Section 2.2 - Prop 2.2.4)
      🔗
    5. I can reformulate and answer questions about span in terms of linear combinations, matrix equations, and geometrically. (Section 2.3)
      🔗
    6. I can reformulate and answer questions about linearly dependent or linearly independent vectors using appropriate computations, and explain the meaning of the results of computations in the language of linear combinations. (Section 2.4)
      🔗
    7. I can find the matrix of a linear transformation using elementary vectors, apply a transformation to a vector or shape, and compose transformations using matrix multiplication. (Section 2.5)
      🔗
    8. I can determine if a matrix is invertible, find an inverse, and use inverses to solve matrix equations. (Section 3.1)
      🔗
    9. I can determine whether or not a set of vectors is a basis for \(\mathbb{R}^n\text{,}\) and give examples and non-examples of bases. (Section 3.2)
      🔗
    10. I can convert a vector given in the standard basis into a vector in another basis and vice versa. (Section 3.2)
      🔗
    11. I can find the determinant of a given matrix using cofactor expansion and explain what information this tells us about the invertibility of a matrix. (Section 3.4)
      🔗
    12. I can find and clearly justify bases for the null space and the column space of a matrix (including why the set of vectors is a basis, i.e., why it is linearly independent and spans the relevant spaces) and thus their dimensions. (Section 3.5)
      🔗
    13. I can verify that a vector is an eigenvector algebraically and explain what this means about the vector geometrically. (Section 4.1)
      🔗
    14. I can use the characteristic polynomial of a matrix \(A\) to identify its eigenvalues, and then find a basis of eigenvectors for each associated eigenspace and, if there is a basis of eigenvectors for \(\mathbb{R}^n\text{,}\) use such a basis to describe the matrix product \(A\xvec\text{.}\) (Section 4.2)
      🔗

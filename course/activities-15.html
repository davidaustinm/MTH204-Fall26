    Worksheet Section 2.5 - Matrix transformations
    

    1.

    Consider the matrix transformation \(T(\xvec) = A\xvec\) where
    🔗
    \begin{equation*} A = \left[ \begin{array}{cccc} 3 \amp 3 \amp -2 \amp 1 \\ 0 \amp 2 \amp 1 \amp -3 \\ -2 \amp 1 \amp 4 \amp -4 \\ \end{array} \right]. \end{equation*}
    🔗

    (a)

    What is the dimension of the vectors \(\xvec\) that are input into \(T\text{?}\) What is the dimension of the vectors \(T(\xvec)\) that are output from \(T\text{?}\)
    🔗
    Solution.
    \(\xvec\) is the input to T and is in \(\mathbb{R}^4\text{,}\) which matches the number of columns of \(A\text{.}\)
    🔗
    \(A\xvec\) is the output from T and is in \(\mathbb{R}^3\text{,}\) which matches the number of rows of \(A\text{.}\)
    🔗
    🔗
    🔗

    (b)

    If we describe this transformation as \(T: \mathbb{R}^n \rightarrow \mathbb{R}^m\text{,}\) what are the values of \(n\) and \(m\) and how do they relate to the shape of \(A\text{?}\)
    🔗
    Solution.
    Here, \(n = 4\) and \(m = 3\) such that \(T: \mathbb{R}^4 \rightarrow \mathbb{R}^3\text{.}\) \(n\) is the number of columns of \(A\) and \(m\) is the number of rows.
    🔗
    🔗
    🔗

    (c)

    Describe all the vectors for which \(T(\xvec) = \zerovec\text{.}\)
    🔗
    Solution.
    We consider the augmented system corresponding to \(A\xvec = \zerovec\text{:}\)
    \begin{equation*} \left[ \begin{array}{cccc|c} 3 \amp 3 \amp -2 \amp 1 \amp 0 \\ 0 \amp 2 \amp 1 \amp -3 \amp 0 \\ -2 \amp 1 \amp 4 \amp -4 \amp 0 \\ \end{array} \right] \sim \left[ \begin{array}{cccc|c} 1 \amp 0 \amp 0 \amp 3 \amp 0 \\ 0 \amp 1 \amp 0 \amp -2 \amp 0 \\ 0 \amp 0 \amp 1 \amp 1 \amp 0 \\ \end{array} \right] \end{equation*}
    which yields the parametric representation of the solution of \(x_1 = -3x_4\text{,}\) \(x_2 = 2x_4\text{,}\) \(x_3 = -x_4\text{,}\) and \(x_4\) is free. Thus, the vectors for which \({T(\xvec) = \zerovec}\) are \(\xvec = \fourvec{-3t}{2t}{-t}{t}\) for \(t \in \mathbb{R}\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2.

    If \(B\) is the matrix \(B = [ \vvec_1 \quad \vvec_2]\) and \(T(\xvec) = B\xvec\text{,}\) what is \(T\left( \twovec01 \right)\) in terms of the vectors \(\vvec_1\) and \(\vvec_2\text{?}\)
    🔗
    Solution.
    \begin{equation*} T\left(\twovec{0}{1}\right) = B\twovec{0}{1} = 0\vvec_1 + 1\vvec_2 = \vvec_2 \end{equation*}
    \begin{equation*} T\left(\twovec{1}{0}\right) = B\twovec{1}{0} = 1\vvec_1 + 0\vvec_2 = \vvec_1 \end{equation*}
    🔗
    🔗
    🔗

    3.

    Suppose that \(C\) is a \(3\times 2\) matrix and that \(T(\xvec) = C \xvec\text{.}\) If
    \begin{equation*} T\left( \twovec10 \right) = \threevec3{-1}1; \,\,\, T\left( \twovec01 \right) = \threevec22{-1}, \end{equation*}
    what is the matrix \(C\text{?}\)
    🔗
    Solution.
    We saw in the previous question that \(T\left( \twovec10 \right)\) pulls out the first column of the matrix representing the linear transformation and \(T\left( \twovec01 \right)\) yields the second column. Thus,
    \begin{equation*} C = \left[ \begin{array}{cc} 3 \amp 2 \\ -1 \amp 2 \\ 1 \amp -1 \\ \end{array} \right]. \end{equation*}
    🔗
    🔗
    🔗

    4.

    More generally we’ll write
    \begin{equation*} \evec_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \\ \vdots \\ 0 \end{bmatrix} ; \evec_2 = \begin{bmatrix} 0 \\ 1 \\ 0\\ \vdots \\ 0 \end{bmatrix} ; \dots ; \evec_n = \begin{bmatrix} 0 \\ 0 \\ 0 \\ \vdots \\1 \end{bmatrix}. \end{equation*}
    If you are given \(T(\evec_1), T(\evec_2),\dots T(\evec_n)\) for a transofrmation \(T(\xvec) = A \xvec\text{,}\) how can you write the matrix \(A\text{?}\)
    🔗
    Solution.
    \begin{equation*} A = \left[T(\evec_1) \,\,\, T(\evec_2) \,\,\, \cdots \,\,\, T(\evec_n)\right] \end{equation*}
    🔗
    🔗
    🔗

    Proposition 8.

    If \(T: \mathbb{R}^n \rightarrow \mathbb{R}^m\) is a matrix transformation given by \(T(\xvec) = A\xvec\text{,}\) then the matrix \(A\) has columns \(T(\evec_j)\text{;}\) that is,
    \begin{equation*} A = \left[T(\evec_1) \,\,\, T(\evec_2) \,\,\, \cdots \,\,\, T(\evec_n)\right] \end{equation*}
    🔗
    🔗

    5.

    Many geometric operations can be described as matrix transformations. Suppose, for instance, that we want to describe the geometric transformation \(T\) that rotates vectors in the plane counterclockwise by \(90^\circ\text{,}\) as shown below. Then \(T(\xvec) = A\xvec\) where \(A\) is a \(2\times2\) matrix.
    🔗

    (a)

    What is \(T\left(\twovec10\right)\) and \(T\left(\twovec01\right)\text{?}\) Use these vectors to find the matrix \(A\text{.}\)
    🔗
    Solution.
    \begin{equation*} T\left(\twovec10\right) = \twovec{0}{1} \end{equation*}
    \begin{equation*} T\left(\twovec01\right) = \twovec{-1}{0} \end{equation*}
    Therefore,
    \begin{equation*} A = \begin{bmatrix} 0 \amp -1 \\ 1 \amp 0 \\ \end{bmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    What vector results when we rotate \(\twovec{-4}{5}\) counterclockwise by \(90^\circ\text{?}\)
    🔗
    Solution.
    Using the matrix \(A\) determined by part (a) above, we have that
    \begin{equation*} T\left(\twovec{-4}{5}\right) = \begin{bmatrix} 0 \amp -1 \\ 1 \amp 0 \\ \end{bmatrix}\twovec{-4}{5} \\ \hspace{6.5cm} = (-4)\twovec{0}{1} + 5\twovec{-1}{0} = \twovec{-5}{-4}. \end{equation*}
    🔗
    🔗
    🔗
    🔗

    6.

    Find the \(2\times2\) matrix \(A\) that reflects vectors across the horizontal axis as shown below. What is the result of reflecting \(\twovec{-4}{5}\) across the horizontal axis? Use the matrix \(A\text{,}\) then verify your answer makes sense by thinking geometrically.
    🔗
    Solution.
    To find the corresponding matrix \(B\) that represents this linear transformation, we consider the affect of \(T\) on \(\evec_1\) and \(\evec_2\text{.}\)
    \begin{equation*} T\left(\twovec{1}{0}\right) = \twovec{1}{0} \\ T\left(\twovec{0}{1}\right) = \twovec{0}{-1} \\ \end{equation*}
    This gives a \(B\) matrix of \(B = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}.\) Then, let’s see the result of applying this linear transformation to \(\twovec{-4}{5}\text{.}\)
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \\ \end{bmatrix}\twovec{-4}{5} = (-4)\twovec{1}{0} + 5\twovec{0}{-1} = \twovec{-4}{-5}. \end{equation*}
    🔗
    🔗
    🔗

    7.

    Suppose that we work for a company that produces baked goods, including cakes, donuts, and eclairs. Our company operates two plants, Plant 1 and Plant 2. In one hour of operation,
    🔗
    • Plant 1 produces 10 cakes, 50 donuts, and 30 eclairs.
      🔗
      🔗
    • Plant 2 produces 20 cakes, 30 donuts, and 30 eclairs.
      🔗
      🔗
    🔗

    (a)

    If plant 1 operates for \(x_1\) hours and plant 2 for \(x_2\) hours, how many cakes \(C\) do they produce in total? How many donuts \(D\text{?}\) How many eclairs \(E\text{?}\)
    🔗
    Solution.
    For each plant we want to multiply the rate of production of each dessert by the number of hours of operation. This yields the following for Plant 1:
    \begin{equation*} C_1 = 10x_1 \,\,\,\,\, D_1 = 50x_1 \,\,\,\,\, E_1 = 30x_1. \end{equation*}
    And, for Plant 2, we have:
    \begin{equation*} C_2 = 20x_2 \,\,\,\,\, D_2 = 30x_2 \,\,\,\,\, E_2 = 30x_2. \end{equation*}
    To find the total amount accross both plants, we have the following set of equations:
    \begin{equation*} C = C_1 + C_2 = 10x_1 + 20x_2 \\ D = D_1 + D_2 = 50x_1 + 30x_2 \\ E = E_1 + E_2 = 30x_1 + 30x_2 \\ \end{equation*}
    🔗
    🔗
    🔗

    (b)

    We define a matrix transformation \(T\left(\twovec{x_1}{x_2}\right) = \threevec CDE\) where \(\threevec CDE\) represents the quantities of baked goods produced when the the fist plant runs for \(x_1\) hours and the second plant runs for \(x_2\) hours. If \(T(\xvec) = A\xvec\text{,}\) what are the dimensions of \(A\text{?}\)
    🔗
    Solution.
    \(A\) is size \(3\times 2\) because the number of rows in the input is 2 and the number of rows in the output is 3. The size of \(A\) has its number of rows as the number of rows of the output and the number of columns as the number of rows of the input.
    🔗
    🔗
    🔗

    (c)

    Find the vector \(T\left(\twovec 10\right)\) and the vector \(T\left(\twovec 01\right)\text{.}\) Then write the matrix \(A\text{.}\)
    🔗
    Solution.
    \begin{equation*} T\left(\twovec 10\right) = \threevec{10}{50}{30} \end{equation*}
    and corresponds to the coefficients of \(x_1\text{.}\)
    \begin{equation*} T\left(\twovec 01\right) = \threevec{20}{30}{30} \end{equation*}
    and corresponds to the coefficients of \(x_2\text{.}\) This yields a matrix \(A\) of:
    \begin{equation*} A = \begin{bmatrix}10 \amp 20 \\ 50 \amp 30 \\ 30 \amp 30 \\ \end{bmatrix}. \end{equation*}
    🔗
    🔗
    🔗

    (d)

    If we operate plant 1 for 40 hours and plant 2 for 50 hours, how many baked goods have we produced? Try to use the matrix \(A\) from part (c) here.
    🔗
    Solution.
    This set-up translates to the following matrix-vector multiplication:
    \begin{equation*} \begin{bmatrix}10 \amp 20 \\ 50 \amp 30 \\ 30 \amp 30 \\ \end{bmatrix}\twovec{40}{50} = \threevec{1400}{3500}{2700}. \end{equation*}
    🔗
    🔗
    🔗

    (e)

    The marketing department says we need to produce 1500 cakes, 4700 donuts, and 3300 eclairs. Is it possible to meet this order? If so, how long should the two plants operate?
    🔗
    Solution.
    We want to try and find the vector \(\xvec\) such that \(A\xvec = \threevec{1500}{4700}{3300}\text{.}\) Using Sage,
    🔗
    This gives a solution vector of \(\xvec = \twovec{x_1}{x_2} = \twovec{70}{40}\text{.}\) This means that Plat 1 should operate for 70 hours and Plant 2 for 40 hours.
    🔗
    🔗
    🔗

    (f)

    Suppose that
    🔗
    • Each cake requires 4 units of flour and 2 units of sugar.
      🔗
      🔗
    • Each donut requires 1 unit of flour and 1 unit of sugar.
      🔗
      🔗
    • Each eclair requires 1 unit of flour and 2 units of sugar.
      🔗
      🔗
    🔗
    Suppose we make \(C\) cakes, \(D\) donuts, and \(E\) eclairs. How many units \(F\) of flour and units \(S\) of sugar are required?
    🔗
    Solution.
    \begin{equation*} F = 4C + 1D + 1E \\ S = 2C + 1D + 2E \\ \end{equation*}
    🔗
    🔗
    🔗

    (g)

    Write a matrix \(B\) that defines the matrix transformation \({R\left(\threevec CDE\right) = \twovec FS}\text{.}\)
    🔗
    Solution.
    To find the matrix \(B\text{,}\) we want to look at the transformation \(R\) acting on the vectors \(\evec_1, \evec_2,\) and \(\evec_3\text{.}\)
    \begin{equation*} R\left(\threevec 100\right) = \twovec{4}{2}, \end{equation*}
    where the resulting vector represents the coefficient of \(C\) for the flour (\(F\)) and sugar (\(S\)). Similarly, we have
    \begin{equation*} R\left(\threevec 010\right) = \twovec{1}{1} \\ R\left(\threevec 001\right) = \twovec{1}{2} \end{equation*}
    which yields a \(B\) matrix of
    \begin{equation*} B = \begin{bmatrix} 4 \amp 1 \amp 1 \\ 2 \amp 1 \amp 2 \end{bmatrix}. \end{equation*}
    🔗
    🔗
    🔗

    (h)

    If plant 1 operates for 30 hours and plant 2 for 20 hours, how many units of flour and sugar are required?
    🔗
    Solution.
    To find the amount of flour and sugar, we first need to find the resulting amounts of cakes, donuts, and eclairs. Then, we can transform this information into the amount of flour and sugar. This means we first need to matrix multiply by \(A\) and then multiply by \(B\text{.}\)
    \begin{equation*} B\left(A\twovec{30}{20}\right) = \twovec{6400}{6500}. \end{equation*}
    🔗
    So, 6400 units of flour and 6500 units of sugar are needed.
    🔗
    🔗
    🔗

    (i)

    Find the matrix that represents the transformation \({P\left(\twovec{x_1}{x_2}\right) = \twovec FS}\) that represents the ingredients needed when the plants are operated for \(\twovec{x_1}{x_2}\) hours.
    🔗
    Solution.
    The matrix \(P\) represents the combination of the action of first multiplying by \(A\) and then multiplying by \(B\text{.}\) Therefore, \(P = BA\)
    🔗
    🔗

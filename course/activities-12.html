    2.

    Now we’ll look at the span of sets of vectors in \(\real^3\text{.}\)
    🔗

    (a)

    Consider the vector \(\vvec =\threevec121\text{.}\) Give a geometric description of \(\laspan\vvec\) and a rough sketch of the span below.
    🔗
    Solution.
    Geometrically, this is a line! (NEED VISUAL HERE)
    🔗
    🔗
    🔗

    (b)

    Now consider the vectors
    \begin{equation*} \evec_1 = \threevec100,~~~ \evec_2 = \threevec010. \end{equation*}
    Give a geometric description of \(\laspan{\evec_1,\evec_2}\) and a rough sketch of the span below.
    🔗
    Solution.
    Geometrically, this is the \(xy\)-plane!
    🔗
    🔗
    🔗

    (c)

    Let’s look at this situation algebraically. If we write \(\bvec=\threevec{b_1}{b_2}{b_3}\text{,}\) what condition on the components of \(\bvec\) must be satisfied if the equation
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \\ \end{bmatrix} \xvec = \bvec \end{equation*}
    is consistent? What condition on the components of \(\bvec\) must be satisfied for \(\bvec\) to be in the span of \(\evec_1\) and \(\evec_2\text{?}\)
    🔗
    Solution.
    First, because of the last row of zeros in the coefficient matrix (which is in row reduced echelon form), it must be true that \(b_3 = 0\) in order for the system to be consistent. There are no restrictions on \(b_1\) or \(b_2\text{.}\)
    🔗
    Algebraically, to see if \(\bvec\) is in the span of \(\evec_1\) and \(\evec_2\text{,}\) let \(\xvec = \twovec{x_1}{x_2}\text{.}\) We consider
    \begin{equation*} x_1\threevec{1}{0}{0} + x_2\threevec{0}{1}{0} = \threevec{x_1}{x_2}{0}. \end{equation*}
    This shows again that it must be that \(b_3 = 0\text{,}\) but there are no conditions on \(b_1\) or \(b_2\) in order to have a consistent system.
    🔗
    🔗
    🔗

    3.

    Consider the vectors
    \begin{equation*} \vvec_1 = \threevec11{-1},~~~ \vvec_2 = \threevec021,~~~ \vvec_3 = \threevec1{-2}4. \end{equation*}
    🔗

    (a)

    Is the vector \(\threevec4{-3}{-1}\) in \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{?}\)
    🔗
    Solution.
    Consider the augmented system
    \begin{equation*} \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 1 \amp 4 \\ 1 \amp 2 \amp -2 \amp -3 \\ -1 \amp 1 \amp 4 \amp -1 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp 3 \\ 0 \amp 1 \amp 0 \amp -2 \\ 0 \amp 0 \amp 1 \amp 1 \\ \end{array} \right] \end{equation*}
    This result shows the system is consistent with a unique solution. Therefore, it is true that the vector \(\threevec{4}{-3}{-1}\) is in the Span and \({3\vvec_1 - 2\vvec_2 + \vvec_3 = \threevec{4}{-3}{-1}}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    What is the reduced row echelon form of the matrix \(\begin{bmatrix} \vvec_1 \amp \vvec_2 \amp \vvec_3 \end{bmatrix} \text{?}\) You should be able to find this using your work from the last question.
    🔗
    Solution.
    From the previous question we saw that \(\begin{bmatrix} \vvec_1 \amp \vvec_2 \amp \vvec_3 \end{bmatrix} \sim I_3\text{.}\)
    🔗
    🔗
    🔗

    (c)

    What do the pivot positions of this matrix tell you about \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{?}\) Give a geometric description of \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{.}\)
    🔗
    Solution.
    There is a pivot in every row, which means that there is always a solution to \(\begin{bmatrix} \vvec_1 \amp \vvec_2 \amp \vvec_3 \end{bmatrix}\xvec = \bvec\text{.}\) Geometrically, this means that \(\laspan{\vvec_1,\vvec_2,\vvec_3} = \mathbb{R}^3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4.

    Consider the vectors
    \begin{equation*} \vvec_1=\threevec2{-1}0,~~~ \vvec_2=\threevec113,~~~ \vvec_3=\threevec3{-3}{-3}. \end{equation*}
    🔗

    (a)

    Is the vector \(\threevec5{-4}{-3}\) in \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{?}\)
    🔗
    Solution.
    We have the following augmented system:
    \begin{equation*} \left[ \begin{array}{rrr|r} 2 \amp 1 \amp 3 \amp 5 \\ -1 \amp 1 \amp -3 \amp -4 \\ 0 \amp 3 \amp -3 \amp -3 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 2 \amp 3 \\ 0 \amp 1 \amp -1 \amp -1 \\ 0 \amp 0 \amp 0 \amp 0 \\ \end{array} \right] \end{equation*}
    This system is consistent! Therefore, \(\threevec5{-4}{-3}\) is in the \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{.}\) There is a free variable, so there are infinitely many solutions. One such solution/linear combination is: \(3\vvec_1 - \vvec_2 = \threevec5{-4}{-3}\text{.}\) Another is \({\vvec_1 + \vvec_2 = \threevec5{-4}{-3}}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    How about \(\threevec84{11}\text{?}\)
    🔗
    Solution.
    We have the following augmented system:
    \begin{equation*} \left[ \begin{array}{rrr|r} 2 \amp 1 \amp 3 \amp 8 \\ -1 \amp 1 \amp -3 \amp 4 \\ 0 \amp 3 \amp -3 \amp 11 \\ \end{array} \right] \sim \left[ \begin{array}{rrr|r} 1 \amp 0 \amp 2 \amp 0 \\ 0 \amp 1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \\ \end{array} \right] \end{equation*}
    This system is inconsistent! Therefore, \(\threevec8{4}{11}\) is NOT in the \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{.}\)
    🔗
    🔗
    🔗

    (c)

    How many pivot positions does the matrix \(\begin{bmatrix}\vvec_1\amp\vvec_2\amp\vvec_3\end{bmatrix}\) have?
    🔗
    Solution.
    From the coefficient matrix component of the two previous augmented systems, we can see that there are 2 pivots to the matrix \(\begin{bmatrix}\vvec_1\amp\vvec_2\amp\vvec_3\end{bmatrix}\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Give a geometric description of \(\laspan{\vvec_1,\vvec_2,\vvec_3}\)
    🔗
    Solution.
    Because there are two pivots, there is a relationship between the three vectors such that \(\laspan{\vvec_1,\vvec_2,\vvec_3} = \laspan{\vvec_1,\vvec_2}\) and, geometrically, is a plane.
    🔗
    🔗
    🔗

    (e)

    Now suppose that \(\vvec_4 = \threevec132\text{.}\) Is the vector \(\threevec5{-4}{-3}\) in \(\laspan{\vvec_1,\vvec_2,\vvec_3,\vvec_4}\text{?}\) Notice that you already determined whether this vector is in \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{.}\)
    🔗
    Solution.
    Yes, if \(\threevec{5}{-4}{-3}\) is in \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{,}\) then it is in \(\laspan{\vvec_1,\vvec_2,\vvec_3,\vvec_4}\text{.}\) This is because we can always choose the coefficient in front of the \(\vvec_4\) to be 0 in order to have a linear combination. If a vector is added to the span, vectors already determined to be in the smaller span will continue to be in the larger span. However, if vectors are removed from a span such that it is smaller, this conclusion can not be made.
    🔗
    🔗
    🔗

    (f)

    How about \(\threevec84{11}\text{?}\)
    🔗
    Solution.
    Even though this solution was not previously in the \(\laspan{\vvec_1,\vvec_2,\vvec_3}\text{,}\) it could be that it is in \(\laspan{\vvec_1,\vvec_2,\vvec_3,\vvec_4}\text{.}\) We have to check!
    \begin{equation*} \left[ \begin{array}{rrrr|r} 2 \amp 1 \amp 3 \amp 1 \amp 8 \\ -1 \amp 1 \amp -3 \amp 3 \amp 4 \\ 0 \amp 3 \amp -3 \amp 2 \amp 11 \\ \end{array} \right] \sim \left[ \begin{array}{rrrr|r} 1 \amp 0 \amp 2 \amp 0 \amp 2 \\ 0 \amp 1 \amp -1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 0 \amp 1 \amp 1\\ \end{array} \right] \end{equation*}
    This is a consistent system and due to the presence of free variables, has infinitely many solutions. One such solution is \({2\vvec_1 + 3\vvec_2 + \vvec_4 = \threevec{8}{4}{11}}\text{.}\) Therefore, \(\threevec84{11}\) is in the \(\laspan{\vvec_1,\vvec_2,\vvec_3,\vvec_4}\)
    🔗
    🔗
    🔗

    (g)

    How many pivot positions does the matrix \(\begin{bmatrix}\vvec_1\amp\vvec_2\amp\vvec_3\amp\vvec_4\end{bmatrix}\) have?
    🔗
    Solution.
    As seen in the previous solution, there are 3 pivots.
    🔗
    🔗
    🔗

    (h)

    Give a geometric description of \(\laspan{\vvec_1,\vvec_2,\vvec_3,\vvec_4}\)
    🔗
    Solution.
    Since there are 3 pivots, this means that geometrically the span is equivalent to \(\mathbb{R}^3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    5.

    Suppose that you have a set of vectors \(\vvec_1,\ldots,\vvec_{10}\) whose span is \(\real^{8}\text{.}\)
    🔗

    (a)

    What is the shape of the matrix whose columns are these 10 vectors? That is, how many rows and columns does this matrix have?
    🔗
    Solution.
    The 10 vectors make up the columns, so we know the number of columns is 10. If the set of these vectors span \(\real^{8}\text{,}\) then each of the vectors must have 8 elements and live in \(\real^{8}\text{.}\) Thus, the number of rows is 8. This means that the size of the matrix is \(8\times 10\text{.}\)
    🔗
    🔗
    🔗

    (b)

    What do you know about the pivot positions of this matrix?
    🔗
    Solution.
    There is a pivot in every row (but, not every column).
    🔗
    🔗
    🔗

    (c)

    How many pivot positions are there?
    🔗
    Solution.
    8 pivots.
    🔗
    🔗
    🔗
    🔗

    6.

    Suppose that you have a matrix whose columns form a set of vectors \(\vvec_1,\ldots,\vvec_{n}\) whose span is \(\real^{8}\text{.}\)
    🔗

    (a)

    What do you know about the pivot positions of this matrix
    🔗
    Solution.
    There’s a pivot in every row.
    🔗
    🔗
    🔗

    (b)

    How many pivot positions are there?
    🔗
    Solution.
    8 pivots.
    🔗
    🔗
    🔗

    (c)

    What is the smallest possible number of vectors \(n\text{?}\)
    🔗
    Solution.
    Because we have 8 pivots, there is at most one pivot in every column, which means that \(n \geq 8\text{.}\) If there were fewer than 8 columns, we could not have 8 pivots.
    🔗
    🔗
    🔗

    (d)

    Can a set of 27 vectors span \(\mathbb{R}^{30}\text{?}\) Explain why or why not.
    🔗
    Solution.
    No! A \(30\times 27\) matrix can only have at maximum 27 pivots and we would need 30 pivots (one in every row) to span \(\mathbb{R}^{30}\text{.}\)
    🔗
    🔗
    🔗
    🔗

    7.

    Suppose you find a matrix \(A\) such that \(A\xvec = \bvec\) is consistent for every vector \(\bvec\text{.}\) What does this imply about the pivots of \(A\text{?}\)
    🔗
    Solution.
    There is a pivot in every row.
    🔗
    🔗
    🔗

    8.

    Consider the vectors from the first problem:
    \begin{equation*} \vvec_1=\threevec2{-1}0,~~~ \vvec_2=\threevec113,~~~ \vvec_3=\threevec3{-3}{-3}. \end{equation*}
    You should have found
    \begin{equation*} \begin{bmatrix} 2 \amp 1 \amp 3 \\ -1 \amp 1 \amp -3 \\ 0 \amp 3 \amp -3 \end{bmatrix} \sim \begin{bmatrix} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    🔗

    (a)

    Explain how to write \(\vvec_3\) as a linear combination of \(\vvec_1\) and \(\vvec_2\text{.}\)
    🔗
    Solution.
    We can consider the column corresponding to \(\vvec_3\) to be the augmented column, then representing the linear combination of \({x_1\vvec_1 + x_2\vvec_2 = \vvec_3}\text{.}\) Therefore, with the row reduced echelon form give, we have that \({\vvec_3 = 2\vvec_1 - \vvec_2}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Explain how a linear combination \(c_1\vvec_1 + c_2\vvec_2 + c_3\vvec_3\) can be rewritten as a linear combination of just \(\vvec_1\) and \(\vvec_2\text{.}\)
    🔗
    Solution.
    \begin{align*} c_1\vvec_1 + c_2\vvec_2 + c_3\vvec_3 \amp = c_1\vvec_1 + c_2\vvec_2 + c_3(2\vvec_1 - \vvec_2) \\ \amp = c_1\vvec_1 + 2c_3\vvec_1 + c_2\vvec_2 - c_3\vvec_2 \\ \amp = (c_1+2c_3)\vvec_1 + (c_2-c_3)\vvec_2 \end{align*}
    Here, since \(c_1, c_2, c_3\) are any constants, then \(c_1+2c_3\) is also just a constant, as well as \(c_2-c_3\text{.}\) Therefore, this is a linear combination of \(\vvec_1\) and \(\vvec_2\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Explain why \(\laspan{\vvec_1,\vvec_2,\vvec_3} = \laspan{\vvec_1,\vvec_2}\text{.}\)
    🔗
    Solution.
    Any vector that can be written as a linear combination of \(\vvec_1\text{,}\) \(\vvec_2\text{,}\) and \(\vvec_3\) can be written as a linear combination of \(\vvec_1\) and \(\vvec_2\text{!}\) So, \({\laspan{\vvec_1,\vvec_2,\vvec_3} = \laspan{\vvec_1,\vvec_2}}\text{.}\)
